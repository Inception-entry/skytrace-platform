# v0.2.2 发版说明

发布日期：2026-08-02  
平台版本：`0.2.2`  
Git tag（建议）：`v0.2.2`  
基于版本：`v0.2.1`

本版本将平台品牌统一为 **SkyTrace（天巡智控）**，并同步子项目包名、运维脚本与展示文案。**无新业务功能、无数据库迁移**；Keycloak realm、JWT 客户端、消息队列与存储桶等运行时契约仍保持 `uav` 兼容标识。

## 版本策略

延续 [v0.2.0](v0.2.0.md) 的 **平台统一版本** 约定：

- 唯一对外版本号：`0.2.2`（SemVer 补丁）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml` 与平台版本对齐
- 容器镜像建议打 `0.2.2`，或与 CI 生成的 `IMAGE_TAG` 并存
- 建议仓库名：`skytrace-platform`

## 本版主要内容

### 品牌统一为 SkyTrace（天巡智控）

- 根 README、业务端与管理端标题改为 SkyTrace / 天巡智控
- 前端弃用 `peregrine` / `pe-*`，改为 `skytrace-frontend` 与 `st-*` 组件前缀
- 各子项目包名统一为 `skytrace-*`
- Spring / AI 服务展示名改为 SkyTrace

### 运维与部署标识

- `scripts/uav.sh` 重命名为 `scripts/skytrace.sh`，文档与 CI 引用同步更新
- Compose 容器名、网络名改为 `skytrace-*`
- CI Compose 项目名改为 `skytrace-ci`
- Keycloak 展示名称更新为 SkyTrace；realm / clientId 仍为 `uav` / `skytrace-web`（兼容）
- Prometheus 告警组与 Gateway 响应头改为 SkyTrace 品牌

## 已知限制

- 本地目录名 / GitHub 仓库名可能仍为旧名，需自行改为 `skytrace-platform`
- Keycloak realm、JWT、数据库、MinIO、RabbitMQ、Temporal 等运行时契约仍使用 `uav` 前缀，后续单独迁移
- 其余产品能力边界与 [v0.2.1](v0.2.1.md) / [v0.2.0](v0.2.0.md) 相同

## 发版检查清单

1. `main` CI（构建/测试/全栈验收）全部通过  
2. 确认文档命令已改为 `./scripts/skytrace.sh`  
3. 本地 Compose 旧 `uav-*` 容器需先清理再拉起新名称  
4. 打 tag 并创建 GitHub Release

```bash
git status
git push origin main

git tag -a v0.2.2 -m "v0.2.2 平台品牌统一为 SkyTrace 天巡智控"
git push origin v0.2.2
```

GitHub Release 标题建议：

`v0.2.2 — SkyTrace（天巡智控）品牌统一`

## 升级与回滚提示

- 从 `v0.2.1` 升级：无 Flyway 迁移；注意容器名与脚本名变更
- 已有本地环境：停止旧栈后使用 `./scripts/skytrace.sh rebuild`
- 回滚至 `v0.2.1`：换回旧镜像与 `scripts/uav.sh` 即可；数据库结构无变化
