# v0.2.3 发版说明（Sprint A + B 草稿）

发布日期：待定  
平台版本：`0.2.3`  
Git tag（建议）：`v0.2.3`

本版本覆盖 Sprint A/B：设备落库与壳子打磨、任务绑定真实设备、证据可查询。

## 本版主要内容

### 设备域（Sprint A）

- `device` 成为设备唯一真相源（JPA + Flyway `V5` 种子 / `V6` 从 `uav_device` 迁移）
- API：`GET/POST /api/devices`、`GET/PUT /api/devices/{code}`、`POST .../heartbeat`
- 列表在线状态仍由 Redis presence 覆盖（不写回 DB status）
- 业务端新增 `/devices` 设备管理页

### 任务与证据（Sprint B）

- 创建/更新巡检任务时校验设备必须存在
- 任务列表响应增加 `deviceName` / `deviceStatus`
- `GET /api/evidence?taskCode=&alarmEventCode=` 查询证据元数据
- 任务页设备改为下拉选择；支持按任务查看/上传证据

### 业务端壳子（Sprint A）

- 移除 Vite `HelloWorld` 脚手架与无用 counter store
- `/` 重定向到 `/drone`；三维地图壳保留在 `/map`
- 侧栏菜单补齐：任务、设备、知识库、AI 分析、审计中心

### 命名澄清（Sprint A）

- Vue 审计页路由：`/audit`（旧 `/admin` 重定向）
- 产品名：**审计中心**（业务端） vs **系统管理后台**（`:8889`）
- `/api/admin/*` 后端契约保持不变

## 已知限制

- 若本地 MySQL 已执行过旧版 `V5`（写入 `uav_device`），Flyway checksum 可能不匹配：重建数据卷，或对 `flyway_schema_history` 执行 repair 后再启
- 航线 / 飞控 / 视频抽帧 / 默认真实 YOLO 仍属后续 Sprint
- 设备删除、DB status 与 Redis 双向同步未做
- 证据暂无分页/删除/Temporal 归档编排
- 其余限制同 [v0.2.2](v0.2.2.md)

## 验收建议

1. Flyway 迁移后 `GET /api/devices` 返回 `UAV-001` / `CAMERA-001`
2. 创建新设备 → 列表可见 → heartbeat → 状态 `ONLINE`
3. 创建任务时选择真实设备；未知设备编号应失败
4. 上传证据后 `GET /api/evidence?taskCode=...` 能查到；任务页「证据」面板可见
5. 打开 `/admin` 应跳到 `/audit`；右上角文案为「审计中心」
6. `:8889` 仍为系统管理后台入口
