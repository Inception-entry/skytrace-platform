## 本版主要内容

### 设备管理

- 支持删除未被任务或告警引用的设备
- 删除设备时校验任务、告警引用冲突，并返回明确失败
- 删除后同步清理设备 Presence 在线状态

### 设备在线状态与 MQTT 本地联调

- 设备列表每 5 秒静默刷新在线状态
- 页面不可见或已有请求进行中时，不重复发起轮询
- 提供本地 `docker-compose.mqtt.yml` overlay，用于 Mosquitto 与 `device-sim` 心跳模拟
- Java 服务订阅 MQTT 心跳并更新设备 Presence

### 体验与接口契约修正

- 修复浅色主题下顶栏、侧栏与内容区配色不一致的问题
- `ApiResponse.timestamp` 统一改为 UTC `Instant`
- MySQL、RabbitMQ、Temporal 宿主机端口支持通过环境变量配置

### 工程质量与可维护性

- Node BFF 按域拆分 FeatureModule，降低 `AppModule` 耦合
- 管理服务权限边界与构建问题修复
- backend-node 对齐 NestJS 依赖并清理依赖安全扫描阻塞项

## 已知限制

- 证据分页、归档等产品 1.1 后续阶段不在本版本范围内
- MQTT 模拟 overlay 仅用于本地联调，预发和生产默认不启用
- 不包含真实设备认证、设备证书、远程 Broker 运维能力
- 本版本不新增数据库迁移，不涉及 Schema 升级步骤

## 升级注意

- 本地如需验证 MQTT 模拟链路，需显式挂载 `deploy/docker-compose.mqtt.yml`
- 预发和生产继续使用主 Compose 与既有 vision / staging / production overlay，不应启用本地模拟器
- 发布与回滚以不可变镜像 tag `main-<release SHA 前 7 位>` 为准，不使用 `latest`
- 若升级后需要验证关键路径，优先检查设备管理、在线状态、任务链路和管理端权限边界
