发布日期：2026-08-17

## 版本策略

- 唯一对外版本号：`1.2.1`（SemVer **补丁**：缺陷修复 + 文档，无功能增量）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml`（含 `e2e/`）统一对齐为 `1.2.1`
- 生产部署使用不可变镜像 tag `main-<release SHA 前 7 位>`，不要使用 `latest`
- Git tag `v1.2.1` 只指向合入 `main` 的 release commit；**不要挪动** `v1.2.0`

**为何是 1.2.1 而不是 1.3.0：**

- 不是次版本：没有新的产品能力或 Schema
- 相对 `v1.2.0` 的实质代码只有任务动作后的状态轮询修复

## 本版主要内容

### 任务动作后轮询状态（#56）

启动 / 完成 / 取消由 Temporal 异步落库，接口返回不代表任务状态已更新。
原先固定等待 500ms 刷新一次，worker 稍慢则页面停在「待启动」，Playwright
等待「执行中」超时。`DroneView` 改为记录动作前状态，返回后轮询列表直至
该任务状态变化（首次 500ms，之后每秒一次，上限约 20s）。

### 文档

- 重写 `frontend/README.md`，补齐根 README 中 1.2.0 能力说明与目录树（#55）
- 清理过时证据施工稿（phase foundation / checklist / 可贴代码）、产品化方案、
  联调日剧本与个人 Java 学习路线；保留运维主干、证据中心 runbook / 上线 /
  回滚 / 保留策略，以及发版历史
