## 本版主要内容

### 任务动作后轮询状态（#56）

启动 / 完成 / 取消由 Temporal 异步落库，接口返回不代表任务状态已更新。
原先固定等待 500ms 刷新一次，worker 稍慢则页面停在「待启动」，Playwright
等待「执行中」超时。`DroneView` 改为记录动作前状态，返回后轮询列表直至
该任务状态变化（首次 500ms，之后每秒一次，上限约 20s）。

### 镜像扫描与依赖审计

- `backend-ai` 构建时 `apt-get upgrade`，消除 Debian `util-linux` / `libblkid` 的
  Trivy HIGH **CVE-2026-53615**（#72）
- `admin-service` override `deepmerge-ts` `^8.0.1`，过
  `npm audit --audit-level=high`（随 #75 合入，不升级 Nest 大版本）

### CI

- Playwright 安装去掉 `--with-deps`，避免 GH ubuntu-24.04 上 Azure apt 源
  `Ign` 重试拖满 45 分钟被取消（#75）

### 文档

- 重写 `frontend/README.md`，补齐根 README 中 1.2.0 能力说明与目录树（#55）
- 清理过时证据施工稿（phase foundation / checklist / 可贴代码）、产品化方案、
  联调日剧本与个人 Java 学习路线；保留运维主干、证据中心 runbook / 上线 /
  回滚 / 保留策略，以及发版历史（#71）
