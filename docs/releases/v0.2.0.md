# v0.2.0 发版说明

发布日期：2026-08-02  
平台版本：`0.2.0`  
Git tag（建议）：`v0.2.0`

本版本是 UAV 巡检平台的第一个业务闭环里程碑：告警消息流、证据链、视觉推理入口与生产硬化能力已打通，适合演示、联调与预发验证，**尚不建议作为无条件生产完备版（1.0）**。

## 版本策略

本仓库按 **平台统一版本** 发版：

- 唯一对外版本号：`0.2.0`（SemVer）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml` 与平台版本对齐
- 容器镜像建议同时打：
  - `0.2.0`：正式发版
  - `main-<sha>` 或 CI 生成的 `IMAGE_TAG`：日常滚动
- 后续约定：
  - `0.2.x`：修复与小改进
  - `0.3.0`：视频抽帧、默认真实 YOLO、设备/航线领域深化
  - `1.0.0`：生产可值守（真实推理默认可用、完整领域数据、浏览器 E2E、运维手册齐备）

子项目不单独漂移主版本，除非未来抽出可独立发布的公共库。

## 本版主要内容

### 告警与实时闭环

- AI/API 投递识别结果到 RabbitMQ `skytrace.detection`
- Java 消费后落库，并向 Temporal 发送 `alarmDetected` Signal
- 实时事件经 RabbitMQ fanout 到 Node Socket.IO（`alarm.created`）

### 证据链

- 巡检截图/视频上传 MinIO，数据库仅持久化 object key
- 业务端经 `/files/` 反代访问证据
- Flyway 增加证据资产表

### 视觉推理（YOLO26）

- AI：`POST /api/detections/analyze`
- BFF：`POST /api/alarms/analyze`
- 默认 `AI_VISION_BACKEND=mock`（CI/本地不下载权重）
- 可选真实权重：`uv sync --group vision` + `AI_VISION_BACKEND=yolo26` + `yolo26n.pt`
- Docker 可用 `--build-arg INSTALL_VISION=1` 构建含 ultralytics 的镜像

### Redis 业务缓存

- 最近告警短 TTL 缓存
- 设备 heartbeat 在线状态（`POST /devices/{code}/heartbeat`）

### 生产与工程化

- Compose 端口默认绑定 `127.0.0.1`
- admin JWT 密钥强制配置
- admin 镜像纳入 Publish / Deploy
- CI 增加告警/证据链路验收；Deploy(test) 无服务器时可跳过
- 修复 MinIO / BouncyCastle 高危漏洞与 Node lint

## 已知限制

- YOLO 默认仍为 mock；真实推理需额外依赖与权重
- 尚无完整视频抽帧流水线与定制数据集微调
- 设备 / 航线 / 飞控仍以样例接口为主
- 测试以契约/单测/Compose 验收为主，缺少完整浏览器 E2E
- Temporal Nexus 仍为后续演进项
- Vue `/admin` 与独立后台 `:8889` 命名边界需在文档与产品侧继续澄清
  （**已在 v0.2.3 澄清**：业务端 `/audit` 审计中心 vs `:8889` 系统管理后台）

## 发版检查清单

1. `main` CI（构建/测试/全栈验收）全部通过  
2. Dependency Scan / 镜像扫描无阻塞性 HIGH/CRITICAL  
3. 本地或预发冒烟：
   - 登录业务端与管理端
   - 创建告警并确认 Socket.IO 推送
   - 上传证据并访问 `/files/`
   - 调用 `/api/alarms/analyze`（mock 即可）
4. 确认 `deploy/.env` / staging secrets 已更新（尤其 admin JWT、Registry）
5. 打 tag 并创建 GitHub Release

```bash
# 打平台 tag
git tag -a v0.2.0 -m "v0.2.0 巡检告警与视觉闭环里程碑"
git push origin v0.2.0
```

GitHub Release 标题建议：

`v0.2.0 — 巡检告警与视觉闭环里程碑`

Release body 可直接引用本文「本版主要内容」与「已知限制」。

镜像发布（若走现有 Publish workflow）将 `IMAGE_TAG` 设为 `0.2.0`，或使用 tag 触发的发布流水线。

## 升级与回滚提示

- 从旧开发镜像升级到 `0.2.0` 时，注意 Flyway 迁移（证据表）与新增环境变量（`AI_VISION_*`、`CACHE_*`、admin JWT）
- 回滚时保持数据库迁移向前兼容；证据表可保留，业务只读旧数据不受影响
- 视觉后端若从 `yolo26` 切回 `mock`，仅影响识别结果，不影响告警存储结构
