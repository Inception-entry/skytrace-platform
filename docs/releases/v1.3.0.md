# v1.3.0 发版说明

发布日期：2026-09-24  
平台版本：`1.3.0`  
Git tag：合入本说明后打 `v1.3.0`，标成 Latest，不要标 Pre-release  
基于版本：`v1.2.2`

次版本：告警时间增加 UTC 字段、管理端刷新增加 HttpOnly Cookie、基础镜像 digest 与非 root、页面离开后的连接收口，以及生产容器权限。旧客户端仍可使用原来的 `eventTime` 和 JSON `refresh_token`。

不要挪动 `v1.2.2`，也不要挪动 `v1.3.0-rc.1` 到 `v1.3.0-rc.4`。

## 版本策略

- 唯一对外版本号：`1.3.0`
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml`（含 `e2e/`）对齐为 `1.3.0`
- 生产部署使用不可变镜像 tag `main-<release SHA 前 7 位>`，不要使用 `latest`

## 本版主要内容

- `#213` 告警写入带 UTC，响应增加 `eventTimeUtc`
- `#214` 管理端 refresh 同时写入 HttpOnly Cookie
- `#215` 基础镜像 digest、非 root、SBOM、可选入口蓝绿
- `#216` 销毁 Cesium，并取消离开页面后的轮询
- `#217` 告警时间展示、证据批量标签、SSE/Socket 收口、路由按页加载、生产容器权限

## 升级注意

- Flyway `V24` 增加可空列 `event_instant_utc`
- 旧客户端仍可使用 `eventTime` 和 JSON `refresh_token`
- Nginx 容器端口为 `8080`
- Temporal 固定为 `1.28.1`
- 轨迹最多返回 2000 个点
