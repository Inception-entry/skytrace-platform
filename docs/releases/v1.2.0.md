# v1.2.0 发版说明

发布日期：2026-08-12  
平台版本：`1.2.0`  
Git tag：`v1.2.0`  
基于版本：`v1.1.0`

本版本交付「地图实时飞行 + 航线可视化编辑 + 任务轨迹回放」能力，并合入证据中心
Phase 3 上线闭环；同时补齐 MQTT 认证/可选 TLS、Socket.IO 多实例、Temporal 巡检
工作流加厚，以及数据治理与测试短板文档。相对 `v1.1.0`，**新增 Flyway 迁移
V18（证据维护字段）与 V19（遥测历史表）**，升级前请先备份业务库。

## 版本策略

- 唯一对外版本号：`1.2.0`（SemVer **次版本**：功能增量，无故意破坏性 API 变更）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml`（含 `e2e/`）统一对齐为 `1.2.0`
- 生产部署使用不可变镜像 tag `main-<release SHA 前 7 位>`，不要使用 `latest`
- Git tag `v1.2.0` 只指向合入 `main` 的 release commit

**为何是 1.2.0 而不是 1.1.1 / 2.0.0：**

- 不是补丁：含多条产品能力与 Schema 变更
- 不是大版本：对外 REST/Socket 事件向后兼容；本地 MQTT 默认仍关闭

## 本版主要内容

### 证据中心 Phase 3（合入）

- 归档维护能力与 V18 数据迁移
- 管理台与归档维护联调链路
- 归档压测 / 上线预检脚本与运维文档闭环

### 地图实时飞行（MQTT telemetry）

- `device-sim` 对 `UAV-001` 环线上报 `.../telemetry`（含 lat/lon/alt/heading）
- Java 订阅 telemetry → Redis 最新点 + Rabbit 实时事件
- Node 广播 Socket.IO `device.telemetry`
- `/map` Cesium：飞机模型 + 短轨迹折线（约 200 点）

### 航线可视化编辑与任务缩略图

- `/routes`：Cesium Primitive 点选 / 拖拽 / 右键删点，写回 `waypointsJson`
- 航线列表与任务列表展示航线 SVG 缩略图
- RUNNING 任务可跳转「实时地图」

### 任务级遥测落库与回放

- 新表 `device_telemetry_point`（Flyway **V19**）
- 仅当设备存在 `RUNNING` 任务时落库并绑定 `task_code`
- `GET /inspection-tasks/{taskCode}/telemetry` + `/drone`「轨迹回放」播放器

### MQTT 安全与扩展

- 本地 Broker：禁止匿名 + 用户名密码 + ACL（backend 只读 / sim 只写）
- 可选 mqtts：`./scripts/skytrace.sh mqtt-tls-start`（自签证书，默认 insecure）
- 真机独立账号、受信 CA、EMQX 集群仍不在本版默认范围

### 水平扩展与 Temporal

- Node Socket.IO 默认启用 Redis adapter（`SOCKETIO_REDIS_ADAPTER`）
- 巡检工作流：启动前校验、Signal 幂等、最长 24h → `TIMED_OUT`、可查询开始时间与结束原因
- 文档：`docs/horizontal-scaling.md`（含 Java MQTT 单订阅者边界）

### 数据治理与测试补齐

- `docs/data-governance.md`：MySQL 备份节奏、MinIO 生命周期、Qdrant 重建
- 脚本：`minio-lifecycle-apply.sh`、`qdrant-rebuild.sh`、`mqtt-gen-certs.sh`
- Java：任务状态机 / Activity / 航线 waypoints / 遥测落库单测
- 前端契约测试 + Playwright `routes-and-replay.spec.ts`
- `docs/testing.md` 测试地图

## Schema / 迁移

| 迁移 | 内容 |
| --- | --- |
| V18 | 证据维护字段（哈希回填 / 清理认领 / 归档包校验等） |
| V19 | `device_telemetry_point` 任务级飞行历史 |

升级步骤：

1. `./scripts/mysql-backup.sh`（或等价备份）
2. 部署新镜像；`backend-java` 启动时 Flyway 自动迁移
3. 确认 `flyway_schema_history` 含 V18、V19
4. 抽查证据维护接口与 `GET /api/inspection-tasks/{code}/telemetry`

回滚：若必须回退到 `1.1.0` 镜像，**勿直接对已含 V18/V19 的库降代码**；应先评估迁移可逆性或整库点恢复（见 `docs/ops.md` / `docs/data-governance.md`）。

## 已知限制

- MQTT overlay / TLS 演练默认仅本地；预发生产默认 `MQTT_ENABLED=false`
- Java MQTT 订阅按单实例设计；多 Java 副本需 Shared Subscription / 选主（未内置）
- Temporal 仍非飞控逐步编排；证据归档编排未并进巡检主工作流
- 遥测历史无限期增长时需运维清理（见数据治理文档；可选 `telemetry-prune` 脚本）
- 浏览器不直连 MQTT Broker

## 升级注意

- 合入 `main` 后打 tag `v1.2.0`，Publish 产出 `main-<sha7>`
- 预发/生产继续主 Compose；本地演示地图飞行再 `mqtt-start` 或 `mqtt-tls-start`
- Socket.IO 多实例必须共享同一 Redis，且勿关 `SOCKETIO_REDIS_ADAPTER`（除非明确单实例）
- 证据 Phase 3 上线清单仍以 `docs/evidence-center/go-live-checklist.md` 为准
