# v1.2.2 发版说明

发布日期：2026-09-16（候选稿）  
平台版本：`1.2.2`  
Git tag：**先打 `v1.2.2-rc.1`，不要直接打生产 `v1.2.2`**  
基于版本：`v1.2.1`

P0 热修补丁：关审计发布阻断里的凭据、可见性、时间语义和已知 PDF advisory。  
**无新增 Flyway / Prisma 迁移，无故意破坏性 API 变更。** 时间协议仍是上海 `DATETIME`，不是 UTC Instant。

## 现在该不该发生产

**不该。** 代码版本可以先对齐到 `1.2.2`，合入 Keycloak 拆分后打 **`v1.2.2-rc.1`** 进 fresh staging。下面这些还没关，正式 `v1.2.2` tag 要等它们修完或书面豁免：

- Admin refresh 挂起、logout 竞态（RB-08 / RB-09 / AUTH-004）
- `h2`、Admin npm advisory、PDF 页数/超时治理
- Flyway 空库、detection 幂等、整栈回滚、真实域名 OIDC
- 操作日志历史数据清理、已部署 Keycloak 库内开发账号盘点（改 JSON 不会删旧用户）

## 版本策略

- 唯一对外版本号：`1.2.2`（SemVer **补丁**：安全/正确性，无功能增量）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml`（含 `e2e/`）对齐为 `1.2.2`
- 生产部署仍用不可变镜像 tag `main-<SHA7>`，不要 `latest`
- **为何是 1.2.2 而不是 1.3.0：** 没有新能力、没有 Schema、没有把时间协议改成 UTC

## 本版主要内容（P0）

- 操作日志脱敏（#118）：登录/用户请求不再把明文密码写入 `sys_operation_log`
- 去掉 seed 公开默认密码（#157）
- 非 super 不能提权、保护最后一名 super（#158）
- 证据搜索 `includeDeleted=false` 不再变成 `true`（#160）
- 告警 `eventTime` 写入前转到上海墙钟，Java 兼容 `Z`/`+08:00`（#161）
- 证据查询/归档 Instant 按上海 DATETIME 转换（#162）
- `pypdf` 升到含 advisory 修复的 6.18.1（#163）
- 生产 Keycloak 导入不再带三个 `@local.test` 开发账号（待合入 `fix/keycloak-prod-no-dev-users`）

## 已知限制

- 已部署 Keycloak 里若早已导入开发用户，本版不会自动删除，需运维禁用
- `h2 4.3.0`、Admin 依赖 advisory 未升
- Admin 前端无 refresh token 的 401 仍可能把 `isRefreshing` 卡住
- 证据遗留 API 的 `createdAt` 仍是 `LocalDateTime` 墙钟
- 上传/FFmpeg/PDF 页数限额、detection 幂等、空库 Flyway 未做

## 升级注意

- 先合 Keycloak PR，再在 `main` 打 `v1.2.2-rc.1`；**不要**在 RC 验收前打 `v1.2.2`
- 不要挪动 `v1.2.1` / `v1.2.0`
- 生产滚动等正式 tag：`IMAGE_TAG=main-<sha7> ./scripts/deploy-production.sh`
- 历史 `sys_operation_log` 仍可能有旧秘密，需只读扫描后再清理、轮换
