# v0.2.1 发版说明

发布日期：2026-08-02  
平台版本：`0.2.1`  
Git tag（建议）：`v0.2.1`  
基于版本：`v0.2.0`

本版本为 `v0.2.0` 后的首个补丁版，修复全栈 CI 中告警/证据链路验收失败问题，**无新功能、无数据库迁移**。建议所有 `0.2.0` 部署直接升级。

## 版本策略

延续 [v0.2.0](v0.2.0.md) 的 **平台统一版本** 约定：

- 唯一对外版本号：`0.2.1`（SemVer 补丁）
- 所有子项目 `package.json` / `pom.xml` / `pyproject.toml` 与平台版本对齐
- 容器镜像建议打 `0.2.1`，或与 CI 生成的 `IMAGE_TAG` 并存

## 本版修复内容

### Node BFF — 检测告警字段透传

- `POST /api/alarms/detections` 正确将 `imageObjectKey` / `videoObjectKey` 转发至 Java `/detections/alarms`
- 为 `CreateAlarmDto` 可选字段补充 `class-validator` 装饰器，避免全局 `ValidationPipe(whitelist: true)` 剥离 `confidence`、坐标等字段
- 修复告警落库后 `imageUrl` 为空，导致 `verify-alarm-evidence.sh` 证据链验收失败

### Java — Redis 最近告警缓存

- 禁止缓存空的最近告警快照
- 在事务提交后再失效缓存，防止 CI 轮询读到陈旧的空列表

## 发版检查清单

1. `main` CI（构建/测试/全栈验收）全部通过  
2. `verify-alarm-evidence.sh` 验收通过（告警落库含 `imageUrl`，Temporal Signal 对齐）  
3. Dependency Scan / 镜像扫描无新增阻塞项  
4. 打 tag 并创建 GitHub Release

## 升级与回滚提示

- 从 `v0.2.0` 升级：仅需替换 `backend-node` 与 `backend-java` 镜像；无 Flyway 迁移、无新增环境变量
- 回滚至 `v0.2.0`：直接换回旧镜像即可；数据库结构无变化
- 若已手动打过 `v0.2.0` tag，本版在其基础上追加两个 fix commit
